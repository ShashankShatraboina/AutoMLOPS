# AutoMLOPS 🚀

An end-to-end AutoML + MLOps platform that automates machine learning workflows from data preprocessing to model deployment. This project provides an interactive Streamlit interface for building, training, evaluating, and deploying ML models with minimal manual effort.

## ⚡ Installation

Clone the repository:

```bash
git clone https://github.com/ShashankShatraboina/AutoMLOPS.git
cd AutoMLOPS
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit app:

```bash
streamlit run app.py
```

## 🎯 One-Line Description (Best for GitHub)
**End-to-end AutoML + MLOps platform for automated ML pipelines, model optimization, evaluation, and deployment using Streamlit and Scikit-learn.**

## ✨ Key Features
- **Automated Data Preprocessing** – Handles missing values, encoding, scaling.
- **Intelligent Model Selection** – Trains multiple algorithms (Random Forest, XGBoost, etc.) automatically.
- **Hyperparameter Tuning** – GridSearchCV/RandomizedSearchCV for optimal performance.
- **Real-time Evaluation** – Visual comparisons (confusion matrix, ROC curves, feature importance).
- **Deployment Ready** – One-click model export (joblib) and download.
- **Interactive Dashboard** – Built with Streamlit for seamless user experience.
